**Nature of this register: internal engineering review by an AI assistant plus automated checks, 2026-10-11. It is NOT an independent external security audit and certifies nothing.** Reviewer/verification fields name no person because none has verified these items. "Verified" below means a reproducible check was executed in this session and its evidence is cited.
