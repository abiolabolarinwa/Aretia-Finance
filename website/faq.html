FAQ

Common questions, answered plainly. Every answer here traces back to something already stated in the whitepaper or verifiable on-chain — nothing here is a new claim.

Status
Has ACT launched?
No. The mint is live on Solana mainnet and the treasury multisig is live and tested, but no liquidity pool has been seeded yet, so ACT is not currently tradeable on any exchange. See the roadmap for what's built and what isn't.

The token
Why doesn't ACT show a name, symbol, or logo in my wallet?
Mint authority was permanently revoked immediately after the single initial mint — that's what makes the fixed-supply claim verifiable rather than a promise. The cost of that same irrevocability is that neither the native Token-2022 metadata extension nor the Metaplex Token Metadata program can be attached afterward, since both require an authority the mint no longer has. This is a permanent, deliberate tradeoff, not a bug — see whitepaper §4.2. It's also why some automated risk scanners flag the token: their heuristics are built to catch an active rug pull, not a fixed, immutable supply with no metadata attached. The Verify page exists specifically so you don't have to take that on faith.
Can the total supply ever increase?
No. Mint authority is revoked — there is no code path left by which more ACT can ever be created. Total supply is fixed at 1,000,000,000. Check it yourself on the Verify page, live against mainnet.
Can any wallet holding ACT be frozen?
No. Freeze authority was never granted on this mint, for any wallet, including Aretia Finance LLC's own.
The fee mechanism
How much is the transfer fee, and where does it go?
350 basis points (3.5%) on every transfer, withheld automatically by the Token-2022 standard itself — not by any custom logic Aretia wrote. Of that: 96.5% of the original transfer reaches the recipient net; 2% funds the climate catalyst fund; 1% goes to the liquidity pool; 0.5% is a disclosed management fee that funds Aretia Finance LLC's operational costs of running the treasury. There is no burn allocation. Full breakdown on the Tokenomics page.
Can the team just decide not to route the fee where it says it will?
No — that's the specific distinction this project draws against tokens whose charitable commitments are a stated intention rather than a property of the code. The fee split is enforced by the mint's own on-chain configuration; there's no code path in which a transfer completes without it, and no policy step for anyone to skip.
Trust & security
Has Aretia been independently audited?
Not yet. No formal, independent security audit of the mint configuration or the off-chain scripts that build treasury transactions has been completed — that's stated plainly, not hidden. The Verify tool is a free, instant, zero-trust first check — it is explicitly not a substitute for a real audit.
Who controls the treasury?
No single party. The treasury is a Squads multisig requiring 2 of 3 independent signers to approve any outbound transaction — live on mainnet, with the full propose-approve-execute cycle already tested end to end with a real transaction. No key, including any held by Aretia Finance LLC, can move funds alone.
How do I check any of this myself instead of trusting the site?
Use the Verify page. It queries Solana mainnet directly from your own browser — no Aretia server sits in the request path — and recomputes the mint's authorities, supply, decimals, transfer fee rate, fee authorities, and treasury balance live, showing the result next to the documented claim. The page's own source is visible via View Page Source, so you don't have to trust the verification tool either.
Funding & governance
How does a project actually get funded?
Never as a single lump sum. An approved project's total commitment is divided into tranches, and each tranche releases only after independent verification confirms the prior milestone was actually met. See Details for the full lifecycle.
Do token holders vote on which projects get funded?
Not directly, and not yet. Governance is layered rather than flat, specifically to avoid the failure mode where a well-organized proposal can extract funds from a naive one-holder-one-vote system. Token holders (Layer 1) set funding priorities and category weights, not individual payouts; a technical committee screens applications; independent verification confirms milestones; smart-contract execution releases funds only once both have signed off. Layer 1 activates once the holder base is large enough for a vote to be meaningful — until then, the treasury runs on team-curated grants under the same milestone-verification discipline. See Details.
Can I apply for project funding?
Yes — the application intake is live. See Apply for Funding. Submissions are received and reviewed; automated scoring and milestone-gated disbursement are still being built (see the roadmap), so expect a real review period rather than an instant response.
