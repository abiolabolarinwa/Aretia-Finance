Status
Has ACT launched?
No. The mint is live on Solana mainnet and the treasury multisig is live and tested, but no liquidity pool has been seeded yet, so ACT is not currently tradeable on any exchange. An initial, self-funded liquidity seed is planned, intended to deepen over time rather than launch at full depth on day one. See the roadmap for what's built and what isn't.
Is this financial advice, or an offer to sell a security?
No. Nothing on this site or in the whitepaper is investment advice, and this is not an offer or solicitation to buy or sell any security, token, or financial instrument in any jurisdiction where that would be unlawful. Aretia has not been registered under the securities laws of any jurisdiction.
The token
Does ACT show a name or logo in my wallet?
Yes. ACT's name ("Aretia Finance Protocol") and logo are attached through a Token-2022 MetadataPointer extension referencing a separate Metaplex Token Metadata account, and display correctly in any wallet or block explorer that supports Token-2022 metadata. That metadata account's own update-authority field still names a single key, not the treasury multisig, but its is_mutable flag was permanently set to false at creation, which the Metaplex program itself enforces: no one, including that recorded authority, can change the name, symbol, or logo going forward (see whitepaper Section 12). A name and logo displaying correctly doesn't make a token unique, though, since nothing stops a fraudulent mint from using a matching name and logo of its own; only the mint address is unique, which is why the Verify page checks the address-level facts directly rather than asking you to trust a display name.
Can the total supply ever increase?
No. Mint authority is revoked: there is no code path left by which more ACT can ever be created. Total supply is fixed at 1,000,000,000. Check it yourself on the Verify page, live against mainnet.
Can any wallet holding ACT be frozen?
No. Freeze authority was never granted on this mint, for any wallet, including Aretia Finance LLC's own.
Trust & security
Has Aretia been independently audited?
Not yet. No formal, independent security audit of the mint configuration or the off-chain scripts that build treasury transactions has been completed: that's stated plainly, not hidden. The Verify tool is a free, instant, zero-trust first check; it is explicitly not a substitute for a real audit.
Who controls the treasury?
No single party. The treasury is a Squads multisig requiring 2 of 3 independent signers to approve any outbound transaction, live on mainnet, with the full propose-approve-execute cycle already tested end to end with a real transaction. No key, including any held by Aretia Finance LLC, can move funds alone.
How do I check any of this myself instead of trusting the site?
Use the Verify page. It queries Solana mainnet directly from your own browser (no Aretia server sits in the request path) and recomputes the mint's authorities, supply, decimals, transfer fee rate, fee authorities, and treasury balance live, showing the result next to the documented claim. The page's own source is visible via View Page Source, so you don't have to trust the verification tool either.
