Roadmap

Four phases, not one launch. The mistake to avoid is building later-phase machinery before the foundation is genuinely solid: a treasury multisig still controlled by one person, or governance that exists on paper but not on-chain, undermines every claim this project makes about decentralization and accountability. Phase 1 has to be real before Phase 2 starts.

01Current

Foundation In progress

Mostly what's already built: the token, the treasury, and the application intake are live. The public dashboard, on-chain governance, and a formal project registry are not yet.

  • ✓Token (ACT): live on Solana mainnet, fixed 1,000,000,000 supply, mint authority revoked, fee authorities on the treasury vault. See the whitepaper.
  • ✓Entity formation and initial legal review
  • ✓Treasury multisig with real independent signers, live on mainnet, 2-of-3, tested end to end
  • ✓Project application intake (apply.html), built ahead of schedule. Screening and milestone-gated funding aren't automated yet; submissions are received, not yet processed.
  • ○Transparent transaction allocation live on a public dashboard
  • ○Basic governance (even if team-curated at first)
  • ○Project Registry (v1: manual/simple, not the full on-chain version)
02

Climate finance

Project scoring (Layer 2), funding proposals, milestone-gated funding, and independent verification (Layer 3): turning the application intake into an actual funding pipeline.

03

MRV

Project monitoring, climate-impact measurement, emissions accounting, satellite/geospatial data integration, climate-risk data, independent verification infrastructure, and incentive-token mechanics for ecosystem contributors.

04

Global protocol

Multiple countries and project types, institutional participation, project developers, climate funds, NGOs, additional validators and verifiers, and potentially multi-chain deployment.

Why this order matters: building Phase 3/4 machinery before Phase 1 is genuinely solid would undermine the whole point. A treasury still controlled by one person, or a governance system that exists on paper but not on-chain, makes every claim about decentralization and accountability false in practice even if it's true in the whitepaper. Phase 1 has to be real before Phase 2 starts.
