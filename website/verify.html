Verify this page too. Every check above is computed client-side in JavaScript you can read yourself: right-click → View Page Source, or open DevTools → Sources. There's no server-side step to trust; if this page lied to you, the lie would be sitting in plain text in your own browser.

What this can't do, and why an independent audit still matters: this checks on-chain configuration against our documentation. It doesn't review the off-chain scripts that build treasury transactions for logic bugs, and it doesn't evaluate Token-2022 or Squads internally; those are separate, already-audited programs this project doesn't control. Treat this as a free, instant, zero-trust first check, not a replacement for a real one. RPC reads here are public and read-only: no wallet connection, no signature, no transaction is ever requested.
